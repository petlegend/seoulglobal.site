대표님 GitHub 계정(2단계 인증 사용)에서 만든 이 저장소 전용 열쇠(토큰)를 붙여 넣으세요. 열쇠는 이 창에만 잠시 보관되고 새로고침하면 지워집니다. 브라우저에 저장하지 마세요.

열쇠 만드는 법 (처음 한 번)
  1. github.com → 오른쪽 위 사진 → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  2. Expiration: 7일 또는 30일 (짧을수록 안전)
  3. Repository access: Only select repositories → petlegend/seoulglobal-renewal
  4. Permissions → Repository → Contents: Read and write (다른 권한은 주지 않음)
  5. Generate → 표시된 열쇠를 복사해 위 칸에 붙여 넣기. 열쇠는 메모장·카톡에 남기지 마세요.

법적 문서입니다. 바꾸기 전에 내용을 꼭 확인하세요.
